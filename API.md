# ZhiHui Web 0.6.6 API contract

Base: `/api/v1`; JSON UTF-8. Cookie sessions (HttpOnly, SameSite=Lax, Secure on HTTPS), same-origin writes. Errors: `{ "error": { "code": "...", "message": "..." } }`. Authentication and ownership are enforced server-side. Credentials are write-only. No filesystem paths or generic Tauri RPC.

- `GET /health` -> `{ok:true,version:"0.6.6",build:"5"}` for the current local adapter; public `GET /version` -> `{version,build,capabilities,icp_registration:string|null}`. `icp_registration` is optional deployment metadata from `ZHIHUI_ICP_NUMBER`; absent/blank means null. It is trimmed, limited to 100 Unicode characters and rejects control characters. The site footer renders it as text linked only to `https://beian.miit.gov.cn/`; no custom URLs or HTML are accepted. The archived `0.6.6-web.1` Docker image still reports build `1` and has not received this adapter.
- `POST /auth/login` `{username,password}` -> User; `POST /auth/accept-invite` `{token,username,password}` -> User; `GET /auth/me` -> User; `POST /auth/logout` -> `{ok:true}`.
- User: `{id,username,role:"admin"|"user"}`. `POST /admin/invitations` -> `{token,url,expires_at}`; `GET /admin/users` -> User[]; `PATCH /admin/users/:id` `{disabled:boolean}`.
- `GET /meetings?search=...` -> Meeting[]; `POST /meetings` `{title}` -> Meeting; `GET /meetings/:id` -> `{meeting,transcripts:Transcript[],summary:string,jobs:Job[],recording_state?:"pending"|"running"|"completed"|"interrupted"|null}` (latest recording, including refresh recovery); `PATCH /meetings/:id` `{title}` -> Meeting; `DELETE /meetings/:id` -> `{ok:true}`.
- Meeting: `{id,title,created_at,updated_at,asset_id?:string|null}`. Transcript: `{id,meeting_id,transcript,timestamp,audio_start_time?:number,audio_end_time?:number,speaker?:string|null,source:string}`.
- `POST /meetings/:id/import-text` `{text}` -> `{ok:true}`; `PATCH /meetings/:id/transcripts/:transcriptId` `{transcript?,speaker?}` -> Transcript; `POST /meetings/:id/speakers/rename` `{from,to}` -> `{ok:true}`; `PUT /meetings/:id/summary` `{markdown}` -> `{ok:true}`.
- `POST /assets` multipart `file` -> `{id,name,size,mime_type}`. `GET /assets/:id` supports authenticated download/HTTP Range; `GET /provider-assets/:token` narrowly scoped expiring provider download. `POST /meetings/:id/asset` `{asset_id}` -> Meeting.
- `GET /templates` -> Template[]; `PUT /templates/:id` `{name,description?,prompt}` -> Template; `DELETE /templates/:id` -> `{ok:true}`. Template: `{id,name,description,prompt,builtin:boolean}`.
- `GET /settings` -> `{asr:{configured,key_masked,provider,base_url,model,language,region,protocol,capabilities:{file_transcription,realtime,diarization,max_duration_seconds}},summary:{configured,key_masked,provider,base_url,model,region}}`; `provider` is `"dashscope"` or `"token_plan"`. `PUT /settings` `{asr_key?,summary_key?,asr_language?,asr_base_url?,asr_model?,summary_base_url?,summary_model?,region?}` -> same masked settings; `DELETE /settings/credentials/:purpose` (asr|summary). All values and credentials are per-user; omitted fields remain unchanged. Change a base URL and its model together when switching providers; if a Key is stored, provide a replacement Key in the same request or delete it first. `configured` means a Key is stored, not that the selected protocol is supported.
- `GET /jobs` -> Job[]; `POST /jobs` `{request_id:UUID,kind:"transcribe"|"summary",meeting_id,asset_id?,template_id?,language?}` -> Job; `POST /jobs/:id/cancel` -> Job. `request_id` is mandatory and scoped to the authenticated user. Repeating the same key and original input fields returns the original Job even after completion or restart, before revalidating mutable settings; reusing a key with different fields returns 409. Generate a new UUID only for a new deliberate job; retain the key and original payload when retrying an uncertain/lost HTTP response. Job: `{id,kind,meeting_id,state:"queued"|"running"|"completed"|"failed"|"cancelled"|"interrupted",progress:number,error?:string|null,created_at,updated_at}`.
- `GET /events` SSE hints `{type:"job"|"meeting"|"transcript",...}`; state is always recoverable via REST. Client may poll instead.
- `POST /recordings` `{title,language?}` -> `{id,meeting_id,websocket_path}`; `GET /recordings/:id/stream` WebSocket, authenticated same-origin. Binary frames are 16kHz mono signed little-endian PCM16, bounded frame size; text control `{type:"stop"}`. Server emits `{type:"transcript",transcript:Transcript}`, `{type:"stopped",meeting_id}` or `{type:"error",message}`. WebSocket closure finalizes the received audio and marks interrupted; never silently reconnect a billable recognition session.

Provider addresses use an exact allowlist: DashScope ASR `https://dashscope.aliyuncs.com`, DashScope summary `https://dashscope.aliyuncs.com/compatible-mode/v1`, or the fixed official Token Plan address `https://token-plan.maas.qianwenaiapi.com/compatible-mode/v1` for either purpose. Arbitrary hosts, alternate ports, userinfo, query parameters, and fragments are rejected. DashScope ASR selects `qwen3-asr-flash-realtime` (file jobs use Paraformer-v2); summaries allow `qwen-plus`, `qwen-turbo`, or `qwen-max`. Token Plan selects ASR `qwen-audio-3.0-asr-flash` and summary `qwen3.8-flash`.

The user has approved native ASR and OpenAI-compatible summaries on the same Token Plan service. Build 2 sends private FLAC as Base64 to the fixed native endpoint `https://token-plan.maas.qianwenaiapi.com/api/v1/services/aigc/multimodal-generation/generation`; the stored settings base remains the compatibility base above and ASR `protocol` is `"dashscope_native"`. It permits file transcription up to 5 minutes / 10,000,000 audio bytes, using automatic language detection, without automatic diarization or real-time streaming. Capabilities are `{file_transcription:true,realtime:false,diarization:false,max_duration_seconds:min(300,server_limit)}`. Real-time recording/stream requests remain unsupported; previously recorded audio can be imported as file jobs. Non-auto language, oversized or overlong input fails before paid submission. The full returned text is saved without inferred timestamps or speaker labels. Clients must use the authenticated user's returned ASR capabilities to enable controls.

A local protocol probe returned 400 for OpenAI chat ASR and 200 for native ASR; this is not completed build 2 adapter verification. Summaries continue to use the selected base's `/chat/completions` endpoint. Keys are initially empty for other/new users and are never shared between accounts.

Defaults: invited users only; per-user DB/storage/credentials/templates; public product version 0.6.6; DashScope Beijing; Qwen3 realtime ASR, Paraformer-v2 file ASR, Qwen-Plus summary. Max upload 200 MiB / 2h; 5 GiB user storage; one realtime session per user, two site-wide; one file and one summary job site-wide. Provider tasks persist upstream IDs and resume polling rather than resubmitting after restart. Regular account creation requires a 12–256 character password. The CLI-only `create-admin --local-bootstrap` exception permits 8–256 characters for the local `admin` account, requires loopback bind/origin, and marks the database so a public `serve` configuration refuses startup; the HTTP signup policy is unchanged.
